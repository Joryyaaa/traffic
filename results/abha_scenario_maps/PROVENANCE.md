## VKT interpretation

No observed traffic counts are available, so this work does **not** claim measured
vehicle-kilometres travelled. `vkt_proxy_km` is a modelled network-load proxy:
`sum(Madina segment betweenness * segment length_km)`. It is reported explicitly
as a proxy everywhere.

## S2 limitation

ASDA's proposed Green Road alignment was not present in the repository and was
not found in public sources. S2 therefore uses a clearly-labelled hypothetical
2.0 km alignment connecting two existing network nodes. It is suitable for
pipeline/scenario testing only and must be regenerated when ASDA supplies the
authoritative geometry.
