## Files

### NetworkX structural proxy heatmaps (graph betweenness centrality)

Generated by `scripts/plot_abha_scenarios.py` using NetworkX edge betweenness
centrality as a structural proxy — NOT Madina's actual flow simulation.

- `abha_s0_flow.png` — S0 baseline
- `abha_s1a_flow.png` — S1A one-way NE
- `abha_s1b_flow.png` — S1B one-way SW
- `abha_s0_s1a_s1b_comparison.png` — side-by-side comparison
- `abha_s1a_vs_s1b_corridor_direction.png` — corridor direction diff

### Madina simulation-based flow heatmaps

Generated by `scripts/plot_abha_flow_heatmaps.py` using Madina's betweenness
simulation (the same simulation the RL environment uses).

- `flow_s0.png`, `flow_s1a.png`, `flow_s1b.png` — per-scenario heatmaps
- `flow_comparison_s0_s1a_s1b.png` — side-by-side comparison
- `flow_diff_s1a_vs_s0.png`, `flow_diff_s1b_vs_s0.png` — flow difference maps

### Comparison data

- `scenario_metrics.json` — mean_access, total_flow, mean_trip_dist for each scenario
- `comparison_table.csv` — full comparison including baseline policy returns
- `comparison_table.txt` — formatted text version
